# Community Distribution Check: 0.8.0

Checked on 2026-10-15. This is a preparation record, not a certification of every
supported device or an end-to-end installation result.

## Confirmed

- The [public listing](https://community.obsidian.md/plugins/graphfrontier) shows 0.8.0 and Add to Obsidian. Direct inspection is necessary: search caches can show older versions.
- The inspected Scorecard reports Health: Excellent and Review: Satisfactory, with warnings rather than a clean scan.
- Formatting, ESLint, all 305 tests, release metadata checks and `git diff --check` passed.
- A fresh production bundle built in memory matches `dist/main.js` byte-for-byte.
- Downloaded 0.8.0 `main.js`, `manifest.json` and `styles.css` match the local `dist/` files byte-for-byte.
- README and the installation guide now prioritize Community Plugins; local preparation also adds contribution guidance and an English announcement draft. These changes are not published yet.

## Scorecard Triage

- Sixteen CSS `!important` warnings correspond to sidebar control styling. No styling changes were made without visual regression testing.
- Filesystem access is intentional for desktop HTML export and desktop path discovery. The README now explains this access and export privacy.
- Two `new Function` calls in the bundle originate in AJV dependencies used by MCP. No corresponding calls were found in `src/`. Dependency origin explains the finding; it does not prove absence of risk.
- Vault enumeration supports graph construction; clipboard writes support explicit copy actions. Visual filters are not access-control boundaries.
- Extra release files and missing artifact attestations are reported. ZIP/versions assets were not removed and release workflows were not changed.
- The scanner reports unavailable malware/network scans. Do not interpret Satisfactory as a comprehensive security audit.
- The missing contributing guide is addressed locally by `CONTRIBUTING.md`; the remote scorecard will not reflect an unpublished file.

## Updated Candidate State

The initial checks above describe the published 0.8.0 baseline. Local 0.8.1
preparation now also includes mobile UI, shared color controls and touch-menu
changes. Catalog installation in an Android emulator and physical Android
runtime testing have since completed; see [Android evidence](0.8.0-android-test.md).
An in-process API call through USB debugging is not an MCP connection.
