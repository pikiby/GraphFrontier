# 0.8.0 Demo Recording Plan

Not recorded yet. Use a synthetic vault with 15-25 readable notes and two or
three tags. Keep personal paths, note content, tokens and client configuration
out of frame. Record MP4 first; crop and convert to GIF together afterward.

## Layouts: One Vault, Two Diagrams

Target: 12-18 seconds. Prepare two saved layouts with different positions,
colors and zoom. Switch between them, pause so labels are readable, then switch
back. Show the layout name and graph together. Turn autosave off during setup;
save both intentionally and clear the manual search row before saving.

## Gravity: Arrange By Meaning

Target: 15-20 seconds. Show notes tagged backend and frontend. Create a gravity
center for `tag:backend`, let matching free nodes settle, then move the center.
Optionally raise repulsion slightly to separate nonmatching notes. Avoid pinned
test nodes: pins intentionally prevent attraction from moving them.

## MCP: A Request Becomes A Diagram

Target: 15-25 seconds. Show the graph and a short agent request, not configuration
or credentials. Ask the connected agent to highlight backend notes, give them a
yellow aura, and pin them to the grid. Capture the real before/after result.
Trim waiting time transparently; do not imply a built-in chat or fake execution.

## Optional: Export And Share

Target: 10-15 seconds. Export a chosen subset without note text, open the HTML in
a browser, then pan and zoom. Show that only the chosen nodes and their internal
links remain. Inspect the exported file for metadata before sharing it.
