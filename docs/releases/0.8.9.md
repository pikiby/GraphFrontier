# GraphFrontier 0.8.9

- **Group settings:** use the sliders icon to adjust node visuals, edge color and Strong pull with the same controls as individual nodes. Delete group is now in this menu.
- **Node lists:** manage lists in **Settings → GraphFrontier → Node lists**, or add selected nodes through **Add to list**. Use `list:<id>` in group filters; external scripts can update membership through the API/MCP.
- **Undo and redo:** undo manual moves and pin actions with **Ctrl/Cmd+Z**. Redo with **Ctrl+Y** or **Ctrl/Cmd+Shift+Z**. Automatic physics and visual settings are not included.
- **Automatic backups:** keep one current copy of layouts, lists and preferences outside the plugin folder. Access tokens are excluded. Reinstallation requires explicit restoration or replacement of an existing backup.
- **Safer backup writes:** a verified recovery copy protects the previous backup during updates. Interrupted writes can be recovered through **Restore**. Windows reserved folder names are rejected.
- **Reliable restoration:** backups preserve saved layouts rather than unsaved node movements. Restore reapplies positions and settings to open graphs without scheduling an overwrite of the source backup.
- **Cleaner settings:** Local MCP, Node lists and Backups use consistent sections and compact controls.

Requires Obsidian **1.12.7** or later. Desktop and mobile supported.
