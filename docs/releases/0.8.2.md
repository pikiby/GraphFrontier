# GraphFrontier 0.8.2: Restore The Native Color Palette

Changes since 0.8.1.

- Restore the native color palette for global node colors, Groups, individual
  node settings and painted links.
- Keep compact circular color swatches and the readability, sidebar and touch
  improvements from 0.8.1. Only the replacement RGB/HEX dialog is removed.
- Prevent a pending painted-link color edit from applying to a different layout.

Requires Obsidian 1.12.7 or newer. No layout-format or physics changes.

The native palette follows the platform: Android and desktop dialogs can look
different. This release does not change link-width or highlight behavior.

Validation: 317 automated tests, formatting, ESLint, production build and release
metadata checks. Installed locally on desktop and a physical Xiaomi; the phone
screenshot confirmed the native Android picker. iOS remains unverified.
