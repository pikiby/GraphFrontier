# GraphFrontier 0.9.4

## Export the graph you mean to share

Filter the graph down to the notes you want, then export it as a standalone HTML page. Notes hidden from that view are no longer included just because they exist in the vault. If you enable **Layouts**, the file also needs the notes visible in those other layouts, so readers can switch between them.

This changes newly generated files only. If you shared an older export and want the narrower scope, generate a new file and replace the old one. Included notes can still contain sensitive text and metadata; review them before sharing. API clients can omit note bodies with `includeContents: false`.

## Style connections

Choose solid, dashed or dotted links globally, by group or for an individual node. Click an arrow shape to select it, adjust its size, and choose whether it scales with the nodes as you zoom. The eight shapes stay on one row in the compact picker. Exported graphs use the same link styles.

## Connect a local agent

On desktop, GraphFrontier now connects through the official Obsidian CLI instead of listening on an HTTP port. Agent access is on by default; an existing OFF preference stays off. Use **Sets → MCP** or the plugin settings to turn it off. There is no port or token to copy.

If your client used the old HTTP endpoint, replace that entry with the [stdio connector for your vault](../mcp.md#connect-a-client). The graph itself does not require Node.js or an MCP client.

Requires Obsidian **1.12.7+**. To update, open **Settings → Community plugins → Check for updates**.
