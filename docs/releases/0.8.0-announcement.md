# GraphFrontier 0.8.0: Your Graph, Now Programmable

GraphFrontier is an independent graph workspace for Obsidian, with its own
renderer and physics engine. Arrange notes intentionally and save diagrams you
can return to later.

**Keep different views of the same vault.** Named layouts save distinct
arrangements, settings, colors and gravity centers. In 0.8.0, newly captured
snapshots also preserve camera position and zoom, search state and API-selected
node subsets.

**Organize notes around gravity centers.** Use typed filters, such as `tag:backend`,
to attract matching free nodes. Move the center to reshape the diagram, or use
repulsion to give matching notes more room. Gravity centers were introduced in
earlier releases; 0.8.0 makes them controllable through the new API too.

**Let an agent work with the graph you see.** The new JavaScript API and optional
embedded MCP server expose 32 tools. Connected clients can search and highlight
notes, adjust colors and physics, manage layouts and recovery copies, arrange
nodes, and export a focused HTML diagram.

For example:

> Create an Architecture layout. Show notes tagged backend and their direct
> neighbors, pin them to the grid, and color the entry points yellow. Save the
> layout and export it as HTML without embedding note text.

The exported graph keeps its positions, with pan, zoom, hover and optional note
previews, without running the physics simulation.

MCP is desktop-only, disabled by default and authenticated on localhost. Setup
examples cover Codex, Claude Code and OpenCode 1.x. No separate GraphFrontier
server installation is required. You bring your own MCP client; there is no
built-in AI chat or included model subscription. Connect only trusted clients:
they can read graph data and change layouts, and their model provider may receive
data they retrieve. Exports can contain paths and metadata even without note text.

This release also fixes pinned-node influence on free nodes and improves
save/load ordering and recovery around layout operations.

Install through **Settings -> Community plugins -> Browse -> GraphFrontier**.
