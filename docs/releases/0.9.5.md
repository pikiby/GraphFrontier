# GraphFrontier 0.9.5

## Built-in desktop MCP server without external CLI execution

On desktop, GraphFrontier now runs its MCP server directly inside the plugin on `127.0.0.1` instead of launching an external `obsidian` CLI subprocess (`child_process`). This removes the `Shell Execution` review warning and removes the need for a separate Node.js installation or enabling the Obsidian CLI.

- Agent access remains **ON by default** on desktop in **Sets → MCP** (or plugin settings); an existing `OFF` preference stays off.
- While enabled, GraphFrontier writes its ready-to-use local connection URL (`http://127.0.0.1:<port>/mcp/<secret>`) to `.obsidian/plugins/graphfrontier/mcp.json`. Ask your agent to connect using that file, or register the URL directly — see [MCP connection instructions](../mcp.md#connect-a-client).
- If you previously registered the `0.9.4` `--mcp-stdio` command, replace that client entry with the local URL from `mcp.json`.

## Catalog compatibility

- Replaced `column-gap` with `gap` in the link-style strip (`styles.css`) to resolve the Obsidian catalog CSS compatibility warning without changing layout or spacing.
- Removed unused HTTP wrapper dependencies from the bundle (`@hono/node-server` / `hono` are not bundled).
- Graph rendering, physics, layouts, and HTML export behavior are unchanged from `0.9.4`.

Requires Obsidian **1.12.7+**. To update, open **Settings → Community plugins → Check for updates**.
