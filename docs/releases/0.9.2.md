# GraphFrontier 0.9.2

## Standalone HTML exports

- The exported page now runs GraphFrontier on a snapshot of the graph. It retains positions, camera, theme, link styles, group and node overrides, and subgraph containers. Click a note to read it in the side panel.
- Choose **Physics**, **Settings menu**, **Layouts**, and **Saves** separately. Share a fixed diagram without controls, or an interactive graph with draggable nodes and switchable layouts.
- **Save layout** is manual and desktop-only in supported browsers. Mobile HTML has no Save. Browser exports never autosave; autosave in Obsidian is unchanged. With Layouts but without Saves, readers can switch layouts without creating, renaming, or deleting them.
- **Before sharing:** a full HTML export can include note text and vault metadata even for nodes hidden from view. A visual filter is not a privacy boundary.

## Graph controls

- Choose a circle or a polygon with 3–8 sides in **Display**. Groups and individual nodes can override the shape; selection outlines and color swatches follow it.
- **Grow** replays graph formation in note creation order and can be undone in one step. **Wave** traces links from a clicked node without moving the graph.
- **Sets → Simulation → Physics steps** controls how many steps run per frame (1–5, default 3). Dragging still uses one step.
- **Undo** and **Redo** are now available in the graph header and share history with the keyboard shortcuts.
- Fixed search suggestions: selecting a search parameter now shows its values instead of repeating the parameter list.

## API and MCP

- API exports use the same standalone viewer with physics and settings enabled. Pass `nodeIds` to restrict the export to those notes, links between them, and their active-layout data. Set `includeContents: false` to omit note text; metadata is still included.
