# GraphFrontier 0.8.8

- **Local GraphFrontier:** a separate pane following the active note and its direct neighbors, with independent settings, pins and layout state. Open it from the command palette, a note's **Open linked view**, or a node's **Other** submenu. Settings start hidden.
- **Add to search:** restored modifier-click selection, configurable under **Selection** (default: **Alt + click**).
- **Filter:** all same-name nodes and their connections remain visible, rather than only the first match.
- Fixed local graph camera centering when opening a specific note from a menu.
- Updated vulnerable dependencies, including `body-parser`, `fast-uri`, `qs` and development tooling.
