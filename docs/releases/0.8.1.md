# GraphFrontier 0.8.1: Mobile Controls And Readability

Changes since 0.8.0.

Requires Obsidian 1.12.7 or newer. Compatibility entries for earlier plugin
releases are unchanged.

## Improvements

- Sidebar height respects the view header, visual viewport and floating mobile
  navigation, keeping Save layout, Load layout and Export to reachable.
- Consistent bordered search fields, compact color swatches, slider dimensions
  and geometric collapse arrows on desktop and mobile.
- Better text, slider, separator and graph-link contrast using theme colors.
  Existing node/group colors and configured link widths are preserved.
- A compact RGB/HEX color picker replaces operating-system color dialogs.
  Apply/Cancel are explicit; an invalid HEX value can be corrected with a slider.
  A layout switch invalidates a pending color edit instead of changing another layout.
- Long-press empty graph space to open Create gravity node. Node holds keep their
  existing context actions; movement, early release and a second finger cancel
  pending holds. Mouse and touch share the same context-menu implementation.

## Verification And Limits

This release passes 317 automated tests. An isolated desktop Obsidian 1.12.7
run verified light/dark controls, invalid HEX recovery, Apply, and rejection of
a pending color edit after switching layouts.

Android runtime testing covered an Android 15 emulator and a Xiaomi Android 11
phone with Obsidian 1.14.4. Clean-vault installation through the catalog was
verified for published 0.8.0; subsequent fixes used local candidate assets.
See [Android evidence](0.8.0-android-test.md) for test conditions and limitations.

On one synthetic graph of 1005 nodes and 2957 links, four-second settled-camera
measurements had mean animation-frame intervals of 16.7 ms. Restarting physics
increased the mean to 85.9 ms. This is not a general FPS guarantee; active
simulation on older phones can temporarily reduce responsiveness.

MCP remains optional and desktop-only. Internal API testing over Android USB
debugging does not provide mobile MCP support. Touch box selection is not
implemented. iOS remains unverified. No physics changes are included in this patch.
