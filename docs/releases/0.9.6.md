# GraphFrontier 0.9.6

## Fix Grow timing on filtered graphs and mid-run stop

- **Grow** now schedules only currently visible nodes when filters (`Include only`, `Exclude`, hidden groups, or search) are active. This eliminates silent pauses caused by hidden notes and leaves hidden note positions untouched.
- While **Grow** is running, its button changes to **Stop** so you can finish early and restore all visible nodes right away.
- Using **Undo** (`Ctrl/Cmd+Z` or the header button) or switching/loading a saved layout while **Grow** is active now stops it cleanly and restores pre-Grow coordinates as one undo step.

Requires Obsidian **1.12.7+**. To update, open **Settings → Community plugins → Check for updates**.
