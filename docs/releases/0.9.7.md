# GraphFrontier 0.9.7

## Large-graph physics, mid-zoom rendering speed, and menu polish

- **Adaptive P3M repulsion & FIRE velocity alignment**: dense, low-damping node pockets settle smoothly without perpetual jitter or oscillation.
- **Batched Canvas 2D node rendering**: smooth frame times across mid-zoom levels on large graphs, and skipping all border color/bucket calculations when **Node border** is `0`.
- **Physics & menu refinements**: raised minimum **Repel strength** to `3`, kept **Grow** and **Wave** expanded inside the collapsible **Effects** section, and temporarily removed **Frame** options from text labels.

Requires Obsidian **1.12.7+**. To update, open **Settings → Community plugins → Check for updates**.
