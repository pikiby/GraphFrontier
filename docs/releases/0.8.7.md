# GraphFrontier 0.8.7

Changes since 0.8.6.

## Attachments

Attachments are ordinary graph nodes: they share node sizing, link distance and
physics with notes. Enable **Show attachments** to include linked files, and
**Show unlinked attachments** to include other vault files. The normal **Show
orphans** control still determines whether unlinked nodes are visible.

The **File type** multi-select filters linked and unlinked attachments. Search is
case-insensitive and ignores the leading dot; exclusions are remembered per layout,
even when a type disappears, while newly encountered types are allowed by default.
An attachment color can be set per layout, with individual and group colors taking
precedence. Attachment labels include their file extensions in the graph and static
HTML export. Ordinary labels and hover highlighting remain, without separate hover
name plates.

Clicking a file opens it in an Obsidian editor or viewer registered for its type,
including installed view plugins; unsupported formats fall back to the system's
default external app.

## Selection And Layout

Right-click a selected node or the background to use compatible actions on the
selection. Batch pinning, unpinning and visual settings show eligible counts; copy
actions provide names and paths, and **Ctrl+C** / **Cmd+C** copies selected names
without overriding normal text copying. Destructive and other single-node actions
remain single-target.

Grid line thickness can be adjusted from 0.1 to 1 CSS pixel. Grid placement ignores
stale occupancy from nodes outside the current graph scope or no longer present.
Repel strength now reaches 200 and repel radius 1000; their defaults remain 51 and 265. On opening a root or subgraph pane, saved positions and camera are restored and
free nodes resume settling automatically; explicit Load/Reset restoration stays paused.

See [settings](../settings.md), [usage](../usage.md), and [hotkeys](../hotkeys.md)
for details.
