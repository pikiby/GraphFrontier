# GraphFrontier 0.8.3: One-Click Export And Release Provenance

Changes since 0.8.2.

## Export Without A Dialog

**Export to** now saves `graphfrontier-static.html` directly in the current vault
root and displays its location. No folder or filename prompt is needed. Exporting
again replaces that file. Previously remembered export destinations are ignored.

The graph remains an interactive standalone HTML file with fixed node positions,
pan/zoom, hover and optional note previews. Inspect its contents before sharing:
exports can contain note text, paths and metadata.

## Vault-Native File Handling

Desktop and mobile now share a single implementation using Obsidian's Vault API.
Absolute export paths and desktop-folder discovery have been removed. The plugin
runtime no longer imports Node's `fs` module for export or navigation checks.

**Open path still opens external files and folders** through the operating system.
Vault notes and `obsidian://open` links also remain supported. Missing external
paths are reported using the system's opening error rather than an fs preflight.

## API And MCP

All 32 MCP tools remain available. API/MCP exports accept explicit **vault-relative**
paths, selected node IDs and optional note contents. Existing targets require
`overwrite: true`; export writes are serialized within the plugin and state is
checked again after asynchronous parent-folder creation.

`get_export_locations` now returns the vault name, `vaultRelative: true`, and null
`home`/`desktop` fields. Clients that previously requested absolute desktop paths
must choose a location inside the vault instead.

Storage is governed by Obsidian's adapter. Linked folders are not a physical-path
sandbox, and the queue does not coordinate writes from other applications.

## Styling And Build Trust

- Replace 16 `!important` declarations with panel-scoped selectors, preserving
  transparent section controls, arrows, dividers and compact dropdowns.
- Add GitHub build-provenance attestations for the released `main.js` and
  `styles.css`. Attestations establish origin, not a guarantee of security.
- Move Features near the top of the README and place the API/MCP guide after the
  GIF demonstrations. Remove the old 0.8.0 release summary from the README.

## Validation And Limits

325 automated tests cover export behavior, queue/overwrite handling, navigation,
MCP and existing graph functionality. Formatting, ESLint, production builds,
metadata and archive checks pass; repeated production builds match.

Old/new computed control styles matched in 16 isolated desktop combinations of
theme, control state and desktop/mobile CSS classes. Desktop export and refusal
to overwrite were checked live. Updated runtime files were loaded on a physical
Android phone. Live My_workflow MCP connected, exposed 32 tools, read graph state
and returned the new vault-relative export contract; unauthorized requests were
rejected. Live MCP mutation/export testing was not part of that read-only check.

A complete network-traffic audit, exhaustive physical-device visual coverage and
iOS validation remain outstanding. AJV schema validation and the manual-install
ZIP are retained. Directory warnings may remain; no new Scorecard approval is
claimed by this release.

Requires Obsidian 1.12.7 or newer. No layout-format or physics changes.
