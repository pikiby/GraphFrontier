# GraphFrontier 0.9.1

A more consistent sidebar, editable lists and layouts, safer layout transitions,
expanded subgraph actions and Android keyboard fixes. Requires Obsidian 1.12.7 or later.

## Sidebar And Filters

- Groups, filters, custom lists and layouts share compact editor rows. Changes commit on Enter or blur; each editor keeps one empty row, and panel rebuilds preserve scroll position.
- Groups now contains collapsible Groups and Filters sections. Exclude and Include only rules share a reorderable list, with a count of hidden notes.
- Show only groups hides unmatched notes. Existing files only, Show orphans and attachment controls now live under Filters.
- Selection becomes Sets, containing Selection modifiers and Custom lists. Existing saved tab preferences migrate automatically.

## Lists And Layouts

- Create and rename custom lists inline, reorder them, add selected notes, remove members without closing the submenu, or create a matching group.
- List queries accept IDs or names. Name-derived IDs let matching groups reconnect when a list is recreated under the same suitable name.
- Saved layouts appear as selectable rows with Rename and Delete actions. New layout saves the current graph without overwriting an existing name.
- Switching layouts preserves the camera; the Load layout command still restores the saved snapshot and camera.
- With Autosave enabled, pending changes save before switching layouts or closing the view. Settings, colors, groups and rules no longer need node movement to be saved.
- UI-only changes such as tabs, collapsed sections, camera movement and hotkeys do not trigger layout autosave. The existing nonempty-search save restriction remains.

## Node Menus And Subgraphs

- Strong pull is one 0-20 slider for nodes, selections and groups. Zero on a node disables inherited group pull.
- Shorter menu labels omit selection counts. Combine into subgraph leads the selection menu; Combine linked groups a note with its direct neighbors.
- Remove from subgraph releases individual or selected members. Removing all members ungroups the container.
- Ungroup and removal restore members around their original grouping location, retaining moves made inside the subgraph and restoring valid external orbits. Occupied grid cells use the nearest available cell.
- Nested subgraph origins follow their containers. Older subgraphs without an origin retain their container-based fallback.
- Add URL or path and Edit actions open the note's YAML property in the user's view mode. Alias syntax is available in menu hints; the separate Navigation settings section is removed.

## Search And Export Fixes

- Existing files only now correctly distinguishes unresolved links from existing files.
- Line queries match words or quoted phrases within one text line rather than line numbers. Note text loads on first use and refreshes after changes.
- Export folder suggestions prioritize matching folder names and offer up to 50 results.

## Android Fixes

- Restore graph height after the keyboard closes by observing the parent container as well as the capped canvas wrapper.
- Release focused graph inputs when a canvas gesture starts, preventing repeated keyboard reopening while panning, dragging or pinching.

Existing layouts, lists and settings remain supported. No vault notes are changed by
the upgrade itself; adding a URL/path property is an explicit user action.
